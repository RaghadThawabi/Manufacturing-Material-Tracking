description: User direction for management access and employee sign-in.

Admin and Manager should share management responsibilities, with settings editing reserved for Admin.

**Why:** The user explicitly requested the same responsibilities for both, with Admin alone editing settings.

**How to apply:** Keep management reporting access equivalent; reserve company configuration and access administration for Admin. Detailed permissions remain subject to approval.

The user originally requested dedicated work-email sign-in, but authorized keeping the available existing sign-in to manage roles after email delivery setup was declined and Clerk migration was blocked. Admin assigns each employee's role.

**Why:** The current account and invitation experience is confusing for staff; preserving working access is preferable to blocking the project on unavailable setup.

**How to apply:** Preserve existing accounts and company records. Make identity and assigned role clear, explain invitations are not account switching, and do not promise email-code login without configured delivery.
